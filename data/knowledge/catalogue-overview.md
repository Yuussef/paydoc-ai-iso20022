# Finding an ISO 20022 message definition

The official ISO 20022 Message Definitions catalogue is the source to consult when selecting a message identifier and version. Select the relevant message set to locate its available schema and related documentation. Keep the complete message identifier, including version, with every local schema and retrieval result.

An XSD can be used to check whether an XML document conforms to the structure and constraints expressed in that schema. It does not by itself establish conformance with every payment scheme, community, or bank usage guideline. Confirm those rules in the applicable usage documentation.

Source: https://www.iso20022.org/iso-20022-message-definitions

This short note is original project documentation, not an ISO publication and not a substitute for the official definition or usage guide.
